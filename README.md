# IINA Mobile

针对 iPhone 的独立、免费播放器，基于 IINA 的功能设计和部分控制逻辑，使用同源的 mpv 播放引擎。**这是独立移植项目，不是 IINA 官方发行版。**

[下载最新 Release](https://github.com/chen-bliss/IINA-Mobile/releases/latest)

## 已实现

### 0.4.0 更新

- 首页新增最近播放和完整历史列表，保留进度并支持继续播放、删除与清空；可在设置中关闭记录。
- 首页右上角齿轮打开设置，预设默认色彩、HDR、字幕语言与字号、画面比例和流畅度。默认值用于新打开的视频，播放中的调节只影响当前视频。
- 播放时默认收起调节面板，点播放设置按钮打开；控制栏在播放时自动隐藏，轻点画面恢复。
- 新增省电优先：保留硬件解码并限制输出长边到 1920 像素，简化画面处理。默认启用温度适应，设备升温时暂时降低渲染负担。
- 控制栏隐藏后降低状态刷新频率，退出播放器后停止刷新。发热与实际耗电仍需在目标设备、亮度和片源下长时间验证。

### 0.3.0 更新

- 内置 Noto Sans CJK 字体，修复中文 ASS/SRT 缺字方块；保留字幕原有位置与样式。
- 左上角返回键随播放控制栏一起隐藏，轻点画面可恢复。
- SMB 连续读取会预读一个协商大小的数据块，减少小请求造成的往返开销。
- “画质 → 播放表现”新增“画质优先 / 流畅优先”。流畅优先简化缩放和动态亮度分析，仍保留硬件解码、HDR 与色彩调节。
- 详情和真机验证见 [VALIDATION.md](VALIDATION.md)。

### 0.2.0 修复

- 隐藏设置面板后，视频区域在横屏和竖屏下都会扩大到整个屏幕；播放引擎会重新同步渲染尺寸。
- 横竖屏切换保留同一个 Metal 播放表面，避免播放器仍向旧图层输出。
- 播放界面右上角增加“画面大小与比例”：适应屏幕、填满屏幕（裁切边缘）、拉伸铺满，以及原始、16:9、4:3、2.35:1 比例。
- SMB 播放改用内存中的连接令牌，账号密码与原始中文路径不再经过播放引擎的 URL 解析。
- 支持 Windows `域名\用户名` 登录写法，区分认证、列出共享、打开文件和读取失败。
- 长按已有服务器可“编辑并测试连接”。不允许列出共享的服务器可在编辑页手动填写共享名称。

### 播放功能

- 亮度、对比度、饱和度、伽马、色相：实时调节，范围与 IINA 相同，均为 −100 至 100。参数保存在本机，支持一键重置。
- HDR 自动输出、HDR 到 SDR 的色调映射，提供 Auto、BT.2390、Hable、Reinhard、Clip 算法。切换动态范围时重新创建输出，并恢复播放位置。
- 播放面板分别显示 HDR 片源和 EDR 输出状态，不把“可以解码 HDR”当作已经验证 HDR 显示。
- 内封字幕选择、关闭字幕、本地外挂字幕、SMB 外挂字幕、字幕延迟与字号。支持 libass 提供的 ASS 排版。
- SMB2、SMB3 服务器与共享目录浏览、账号登录、目录搜索、直接播放、读取跳转。服务器密码保存在系统钥匙串中，不写进设置文件。
- 本地文件、网络链接、音轨选择、播放速度、进度跳转、截图到“文件”中的应用目录。
- 无广告、无购买、无订阅，全部功能免费。

## 使用

1. 打开应用，选择“连接 SMB 服务器”。
2. 填写名称、服务器 IP 或主机名、共享名称、账号和密码。地址无需填写 `smb://`；端口默认 445。共享名称留空可尝试列出共享。
3. 打开保存的服务器，进入文件夹，点视频开始播放。同目录同名字幕会一并加载，也可从字幕面板手动添加。
4. 播放时使用“画质”面板调色；“自动 HDR”优先尝试 HDR 输出，“映射到 SDR”用于关闭 HDR 输出。
   点右上角设置按钮可隐藏面板；点“画面大小与比例”按钮选择铺满方式。适应屏幕会保留原始画面，必要时有黑边；填满会裁切部分边缘；拉伸会改变画面形状。
5. 手机需要能访问服务器网络。在外网访问家中 SMB，可通过现有 VPN 连接回家中网络。

应用包含自行生成的 SDR 与 HDR10 片段，可用于检查色彩和字幕。测试片段不是电影内容。

## 构建

要求 macOS、Xcode 和 iOS SDK。应用最低支持 iOS 17，当前针对用户的 iPhone Duo、iOS 27.1 构建。项目已包含生成的 `IINAMobile.xcodeproj`。

```sh
python3 Scripts/bootstrap.py
open IINAMobile.xcodeproj
```

在 Xcode 的 Signing & Capabilities 中选择自己的开发团队，选中设备后运行。公开工程不预设开发团队，请使用自己的 Apple 开发账号签名。

Git 仓库不包含大型二进制依赖。首次构建前先运行下方脚本，或把 Release 中的 Dependencies.zip 解压到仓库根目录。`Vendor/MPVKit-Package.upstream.swift` 保存上游下载地址和 SHA-256。

获取校验过的依赖：

```sh
python3 Scripts/bootstrap.py
```

安装 XcodeGen 后，修改 `project.yml` 可重新生成工程：

```sh
xcodegen generate
```

## 测试

默认 `IINAMobile` scheme 包含模型测试和界面测试。SMB 集成测试需要以下隔离测试服务，绑定本机 `127.0.0.1:1445`，不改变电脑的系统文件共享。

```sh
python3 -m venv .qa-venv
.qa-venv/bin/pip install impacket
.qa-venv/bin/python Scripts/smb_qa_server.py
```

使用 `SMBQA` scheme 运行 `IINAMobileTests`，它会开启 `IINA_SMB_QA=1` 并验证成功登录、错误密码、目录、读取、跳转和取消。测试凭据只用于生成的测试片段。

界面测试会验证滑块参数读取、饱和度变化对渲染画面色度的影响、重置、外挂字幕轨道、HDR 片源检测与 SDR 映射，以及 SMB 视频播放。

## 安装与目前限制

- 本次生成的开发版需要对应设备和有效签名。IPA 不是任意 iPhone 都能直接安装的 App Store 安装包。
- 免费 Apple Personal Team 每台设备最多安装 3 个自行签名应用，签名配置通常 7 天到期。该限制来自苹果，与播放器是否收费无关。
- 更新使用原有应用标识，不卸载其他应用，也不消耗新的免费安装名额。硬件 HDR 亮度和实际 NAS 兼容性需要在手机上验证。
- HDR 输出依赖 MPVKit 的 MoltenVK 后端和屏幕能力。Dolby Vision 各类配置、外接屏、AirPlay 和画中画不在此版本的验收范围内。
- 此版本聚焦色彩、HDR、字幕、SMB，尚未移植 IINA 的整个桌面界面、插件系统与所有设置。

开源来源、版本与许可证见 [THIRD_PARTY.md](THIRD_PARTY.md)。测试结果与安装状态见随附的交付说明。

## Release 安装包

公开 Release 提供 `IINA-Mobile-0.4.0-unsigned.ipa`，需使用自己的 Apple 开发账号重新签名后安装，也可以直接从源码用 Xcode 构建。公开包不包含任何个人设备的描述文件或开发签名，不是 App Store 安装包。

- `Dependencies.zip`：构建所需的已校验 iOS / 模拟器二进制依赖，解压到仓库根目录。
- `ThirdPartySources.tar`：第三方播放器组件的固定版本源码归档、构建脚本和来源清单。
- `SHA256SUMS.txt`：Release 附件校验值。
